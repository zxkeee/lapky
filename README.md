# Лапки

Сервіс, що поєднує притулки для тварин в Україні з людьми, які готові допомогти: речами, кормом, грошима,
транспортом або власним часом.

Проєкт складається з трьох частин, які працюють з одними й тими самими даними:

- **вебкарта** — притулки всієї України на карті, їхні актуальні потреби, збори та волонтерські завдання;
- **Telegram-бот** — той самий каталог у месенджері, а також усі дії, що потребують входу: «беру потребу»,
  підписки, запис на завдання, кабінет притулку, модерація;
- **сервер** — єдине джерело правди: REST API на FastAPI і база даних SQLite.

Змінили потребу в кабінеті притулку — вона одразу видна на карті, у боті, а підписники отримують сповіщення.

## Можливості

### Для волонтерів

| Можливість | Де | Опис |
|---|---|---|
| Каталог притулків | карта, бот | Усі опубліковані притулки України, сортування за терміновістю (критичний, високий, звичайний, закриті потреби) |
| Фільтри | карта, бот | Область, 5 категорій потреб (проживання, харчування та здоров'я, догляд, фінанси, волонтерство та авто), 4 види корму, пошук за назвою, містом, адресою |
| Поруч зі мною | карта, бот | Геолокація браузера або Telegram: найближчі притулки з відстанню в кілометрах |
| Беру потребу | бот (з карти — посиланням) | Волонтер позначає, що привезе конкретну річ; притулок одразу отримує його контакт; інші бачать «вже везуть: N» |
| Підписки | бот | На окремий притулок або на всю область; режим «лише термінове» |
| Волонтерські завдання | карта, бот | Вигул, транспорт, прибирання тощо: дата, кількість місць, запис в один дотик, нагадування за добу |
| Збори та соцмережі | карта, бот | Банки monobank, PayPal, Patreon, IBAN, картка; сайт, Instagram, Facebook, Telegram, TikTok, YouTube |
| Мої справи | бот | Мої обіцянки (позначити «привіз» або скасувати), мої завдання, мої підписки |

### Для притулків

| Можливість | Опис |
|---|---|
| Заявка на додавання | Покрокова анкета в боті (`/apply`): назва, область, адреса, точка на карті, телефон, соцмережі |
| «Це мій притулок» | Для притулків, які вже є в базі (імпортовані з відкритих джерел): заявка на керування |
| Кабінет `/my` | Терміновість, потреби, соцмережі, збори (з перемиканням видимості), завдання, телефон |
| Хто що везе | Список волонтерів, які взяли потреби, з їхніми контактами |
| Записані на завдання | Хто записався, закриття завдання з автоматичним повідомленням учасникам |

### Для адміністраторів

| Можливість | Опис |
|---|---|
| Модерація `/moderate` | Черга заявок з деталями, посиланням на точку в OpenStreetMap, кнопками «Схвалити» / «Відхилити» |
| Сповіщення про заявки | Кожна нова заявка приходить адміністраторам у бот |
| Повний доступ до API | Через `X-Admin-Token` або роль `admin`: приховати притулок, позначити як перевірений, редагувати будь-що |

Гроші через сервіс не проходять: зберігаються лише посилання на збори й реквізити, які публікує сам притулок.

## Архітектура

```
                     ┌──────────────────────────────┐
                     │        SQLite (data/)         │
                     │  міграції: backend/migrations │
                     └───────────────┬──────────────┘
                                     │
                     ┌───────────────▼──────────────┐
                     │        FastAPI сервер         │
                     │  /api/...   + вебкарта на /   │
                     │  черга сповіщень (outbox)     │
                     └───────┬──────────────┬───────┘
                 HTTP / JSON │              │ HTTP / JSON + X-Bot-Token
                ┌────────────▼───┐   ┌──────▼─────────────────┐
                │    Вебкарта    │   │      Telegram-бот       │
                │ Leaflet, без   │   │  aiogram 3, без власної │
                │ входу, читання │   │  БД; доставляє outbox   │
                └────────────────┘   └─────────────────────────┘
```

Ключові принципи:

- **Одне джерело правди.** Ні карта, ні бот не мають власних даних і не дублюють бізнес-логіку —
  усі правила (хто що може змінювати, кому слати сповіщення) живуть на сервері.
- **Бот — довірений клієнт.** Він підписує запити секретом `BOT_API_TOKEN` і передає Telegram ID користувача.
  Так сервер знає, хто діє, без окремої реєстрації.
- **Вебкарта лише читає.** Дії, що потребують входу, ведуть у бота через deep-link
  (`t.me/<бот>?start=pledge_12`, `task_5`, `shelter_7`, `claim_7`, `apply`).
- **Сповіщення через чергу.** Сервер записує повідомлення в таблицю `outbox`, бот раз на 15 секунд забирає
  їх і надсилає, з урахуванням лімітів Telegram. Користувачі, що заблокували бота, автоматично відписуються.
- **Схема БД версіонується.** Нові міграції накатуються при старті сервера, наявні дані переносяться.

Стек: Python 3.11+, FastAPI, Pydantic 2, SQLite, aiogram 3, httpx, Leaflet 1.9 + Leaflet.markercluster
(обидві бібліотеки лежать локально у `web/vendor/`, карта не залежить від CDN).

## Швидкий старт

### Локально

```bash
python -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                   # заповнити, див. «Налаштування»
```

Наповнити базу:

```bash
python -m backend.seed                                     # 10 перевірених притулків Києва та області
python scripts/import_osm.py                               # притулки з OpenStreetMap
python scripts/import_web.py scripts/data/shelters_ua.json # ~150 притулків з відкритих джерел
```

Запустити сервер і бота (у двох терміналах):

```bash
uvicorn backend.main:app --reload
python -m bot.main
```

| Адреса | Що там |
|---|---|
| http://127.0.0.1:8000 | вебкарта |
| http://127.0.0.1:8000/docs | інтерактивна документація API (Swagger) |

Тести: `pytest -q`

### Через Docker

```bash
cp .env.example .env
docker compose up --build
```

Сервіс `api` при першому запуску заповнює базу з `backend/seed.py`; сервіс `bot` стартує після нього.
Імпорт з OSM і відкритих джерел запускається окремо командами вище.

## Налаштування

Усі параметри — у файлі `.env` (шаблон — `.env.example`). Файл не потрапляє в git.

| Змінна | Хто читає | Призначення |
|---|---|---|
| `DB_PATH` | сервер | Шлях до файлу SQLite, за замовчуванням `data/lapky.db` |
| `ADMIN_TOKEN` | сервер | Токен повного доступу до API (скрипти, Swagger) |
| `BOT_API_TOKEN` | сервер, бот | Спільний секрет, яким бот підписує запити від імені користувачів. Без нього бот працює лише на перегляд |
| `ADMIN_TELEGRAM_IDS` | сервер | Telegram ID адміністраторів через кому. Дізнатися свій ID — у @userinfobot |
| `BOT_USERNAME` | сервер | Ім'я бота без `@`; потрібне для кнопок «Беру», «Записатися», «Стежити» на вебкарті |
| `BOT_TOKEN` | бот | Токен від @BotFather |
| `API_URL` | бот | Адреса сервера, за замовчуванням `http://127.0.0.1:8000` |
| `WEB_URL` | бот | Публічна адреса вебкарти для кнопок-посилань у боті |
| `COORDINATOR_EMAIL` | бот | Контакт координатора в розділі «Про проєкт» |

Згенерувати `BOT_API_TOKEN`:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

## Дані про притулки

### Джерела

| Джерело | Поле `source` | Як потрапляє | Позначка «перевірено» |
|---|---|---|---|
| Ручний добір команди | `seed` | `backend/seed.py`, 10 притулків Києва й області з офіційних сайтів і ЗМІ | так, з датою |
| OpenStreetMap | `osm` | `scripts/import_osm.py`: усі `amenity=animal_shelter` в Україні, область — за контуром OSM | ні |
| Відкриті джерела | `web` | `scripts/import_web.py` + `scripts/data/shelters_ua.json`: сайти, соцмережі, ЗМІ, каталог Happy Paw (жовтень 2026) | ні |
| Заявки притулків | `application` | анкета в боті, після схвалення адміністратором | так, датою схвалення |
| Адміністратор | `admin` | `POST /api/shelters` | на розсуд адміністратора |

Неперевірені записи показуються з попередженням «дані з відкритих джерел, притулок їх ще не підтвердив».
Попередження зникає, коли представник притулку підтверджує його через «Це мій притулок».

### Правила відбору

- До бази потрапляють лише організації з підтвердженою активністю у 2024–2026 роках і щонайменше одним
  публічним джерелом (поле `source_url`).
- Не включаються: зоготелі, ветклініки, розплідники, центри для диких тварин, закриті притулки.
- **Окуповані території.** АР Крим, Севастополь і Луганська область не імпортуються. У частково окупованих
  областях окремі записи приховує адміністратор (статус `hidden`).
- **Приватність.** Лише публічні контакти самих організацій: без особистих карток, домашніх адрес і імен
  приватних осіб.

### Координати

Якщо відома адреса, точка визначається геокодуванням (Nominatim). Якщо ні — ставиться в центр населеного пункту
з невеликим зсувом, щоб точки не злипалися, а в картці з'являється «точне місце уточнюйте».

### Повторний імпорт

Обидва скрипти імпорту можна запускати повторно: записи оновлюються, а не дублюються. Правлені вручну
(через кабінет, бот або API) не перезаписуються. Скрипти підтримують `--dry-run`; `import_osm.py` також
`--oblast <ключ>`, `--refresh` (оновити кеш Overpass) і `--no-geocode`.

## Ролі й доступ

| Роль | Як отримати | Що може |
|---|---|---|
| Гість | відкрити вебкарту | Переглядати опубліковані притулки, потреби, збори, завдання |
| Волонтер | написати боту | Беру потребу, підписки, запис на завдання, заявки на притулок |
| Менеджер притулку | схвалена заявка `new_shelter` або `claim` | Усе в кабінеті свого притулку; бачить контакти волонтерів, які взяли потреби чи записалися |
| Адміністратор | Telegram ID у `ADMIN_TELEGRAM_IDS` або `X-Admin-Token` | Модерація заявок, приховування притулків, позначка «перевірено», будь-які зміни |

Контакти волонтера (username у Telegram) бачить лише менеджер притулку і лише після того, як волонтер сам
узяв потребу чи записався на завдання. Публічно відображаються тільки лічильники.

## Telegram-бот

### Головне меню

| Кнопка | Дія |
|---|---|
| Усі притулки (карта) | Список за терміновістю, по 8 на сторінку, вибір області, посилання на вебкарту |
| Фільтр за потребами | Категорії потреб і види корму, вибір області |
| Поруч зі мною | Надсилає геолокацію; найближчі притулки й завдання (радіус розширюється до 300 км) |
| Мої справи | Обіцянки, завдання, підписки, мої притулки, модерація (для адміністраторів) |
| Як допомогти | Пояснення способів допомоги, перехід до категорій і завдань |
| Про проєкт | Опис, посилання на карту, додавання притулку |

### Команди

| Команда | Призначення |
|---|---|
| `/start` | Привітання; також приймає deep-link з вебкарти |
| `/menu` | Головне меню |
| `/all` | Усі притулки |
| `/filter` | Фільтр за потребами й областю |
| `/mine` | Мої обіцянки, завдання, підписки |
| `/my` | Кабінет притулку (для менеджерів) |
| `/apply` | Заявка на додавання притулку |
| `/moderate` | Черга заявок (для адміністраторів) |
| `/help`, `/about` | Як допомогти, про проєкт |
| `/cancel` | Скасувати поточну анкету чи редагування |

### Картка притулку

Терміновість, назва, адреса (з відстанню, якщо шукали поруч), телефон, соцмережі; потреби за категоріями з
лічильником «вже везуть»; збори та реквізити; найближчі завдання; дата перевірки або попередження про
неперевірені дані. Кнопки: вебкарта, контакти й маршрут, «Беру потребу», завдання, збори (посиланнями),
підписка, «Керувати притулком» або «Це мій притулок».

## Вебкарта

- Заголовок одразу показує, скільки притулків в Україні чи вибраній області потребують допомоги зараз.
- Легенда терміновості працює як фільтр; вибір області з кількістю притулків; вкладки категорій і видів корму;
  пошук.
- Кластери маркерів забарвлені за найтерміновішим притулком усередині; критичні точки м'яко пульсують.
- «Поруч зі мною» — геолокація браузера, пошук у радіусі 100 км, сортування за відстанню.
- Картка: «Подзвонити», «Маршрут» (Google Maps), «Стежити в Telegram», потреби з кнопкою «Беру»,
  збори з копіюванням реквізитів, волонтерські завдання з кнопкою «Записатися», джерело й дата перевірки.
- Список підвантажується по 50; автооновлення даних раз на хвилину; адаптивна верстка для телефона;
  `Esc` закриває картку.

Параметри адреси:

| Параметр | Приклад | Дія |
|---|---|---|
| `shelter` | `/?shelter=12` | Відкрити картку притулку (на неї веде кнопка з бота) |
| `oblast` | `/?oblast=lvivska` | Відкрити карту з вибраною областю |

## API

Повний контракт, модель даних і коди помилок — у [`docs/API.md`](docs/API.md); інтерактивно — `/docs`.

| Група | Основні ендпоінти |
|---|---|
| Довідники | `GET /api/meta`, `GET /api/oblasts`, `GET /api/health` |
| Притулки | `GET /api/shelters` (фільтри `category`, `subcategory`, `urgency`, `oblast`, `q`, `near`, `radius_km`, `bbox`, `sort`, `limit`, `offset`), `GET/POST/PATCH/DELETE /api/shelters/{id}` |
| Потреби | `POST /api/shelters/{id}/needs`, `PATCH/DELETE /api/needs/{id}` |
| Соцмережі, збори | `/api/shelters/{id}/links`, `/api/shelters/{id}/fundraisers`, `/api/fundraisers/{id}` |
| Волонтерство | `/api/needs/{id}/pledges`, `/api/pledges/{id}`, `/api/me/subscriptions`, `/api/tasks`, `/api/tasks/{id}/signup` |
| Користувач | `GET/POST /api/me`, `/api/me/pledges`, `/api/me/tasks`, `/api/me/applications` |
| Заявки | `POST /api/applications`, `GET /api/applications`, `POST /api/applications/{id}/approve`, `/reject` |
| Службові (бот) | `GET /api/internal/outbox`, `POST /api/internal/outbox/ack`, `POST /api/internal/remind` |

Автентифікація: без заголовків — читання; `X-Bot-Token` + `X-Telegram-User-Id` — дії від імені користувача;
`X-Admin-Token` — повний доступ.

## Розробка

### Структура

```
backend/
  main.py              збирає застосунок, підключає роутери й статичну вебкарту
  routers/             shelters, needs, tasks, users, applications, internal
  models.py            схеми й валідація (Pydantic)
  deps.py              автентифікація: хто робить запит і що йому дозволено
  repo.py              спільні запити: збирання картки притулку, геометрія
  notify.py            формування сповіщень у чергу outbox
  links.py             розпізнавання типу соцмережі та способу збору
  osm.py               розбір і імпорт даних OpenStreetMap
  constants.py         довідники: терміновість, категорії, області, типи посилань і зборів
  db.py, migrations/   підключення до SQLite і версіоновані міграції схеми
  seed.py              початкові перевірені дані
bot/
  main.py              запуск, синхронізація профілю, порядок роутерів
  handlers/            browse, volunteer, apply, manage, moderate
  outbox.py            фонова доставка сповіщень і нагадувань
  api.py               HTTP-клієнт до сервера
  ui.py, texts.py      клавіатури, картки й тексти
  common.py            спільні помічники хендлерів
web/
  index.html           вебкарта (HTML, CSS і JS в одному файлі)
  vendor/              Leaflet і Leaflet.markercluster
scripts/
  import_osm.py        імпорт з OpenStreetMap
  import_web.py        імпорт з відкритих джерел; дані — data/shelters_ua.json
```

### Міграції

Файли `backend/migrations/NNN_назва.sql` або `NNN_назва.py` (з функцією `migrate(conn)`).
Сервер застосовує нові при старті, кожну в окремій транзакції, і записує номер у таблицю `schema_version`.
Щоб змінити схему, додайте файл з наступним номером; наявні міграції не редагуйте.

### Довідники

Категорії, рівні терміновості, області, типи соцмереж і зборів задаються в `backend/constants.py`
і віддаються клієнтам через `/api/meta`, тож карта й бот підхоплюють зміни автоматично.

### Тести

```bash
pytest -q
```

Тести створюють тимчасову базу і не потребують мережі чи Telegram.

## Обмеження та нюанси

- **Кнопки-посилання в боті.** Telegram не приймає `localhost`, тож кнопки на вебкарту з'являються, лише коли
  `WEB_URL` — публічна адреса. Для демонстрації підійде `ngrok http 8000` або `cloudflared tunnel`.
- **Стан анкет у боті** зберігається в пам'яті: після перезапуску бота незавершені анкети треба почати знову.
  Усі збережені дані живуть на сервері й не втрачаються.
- **Неповнота даних.** Каталог з відкритих джерел не вичерпний, особливо для малих міст; основним каналом
  поповнення мають стати заявки притулків.
- **Геокодування.** Nominatim обмежує частоту запитів (1 на секунду), тому імпорт великої кількості записів
  триває кілька хвилин; результати кешуються в `data/`.
- **Скидання бази.** `python -m backend.seed --reset` стирає всі притулки, заявки, обіцянки й завдання.
