# Сценарій демонстрації на захисті (5 хвилин)

**Підготовка за 10 хв до виступу:** `uvicorn backend.main:app`, `python -m bot.main`,
`ngrok http 8000` → адресу в `WEB_URL`, перезапустити бота. Відкрити карту на ноутбуці, бота — на телефоні (екран дзеркалити).

1. **Проблема (30 с).** Притулки Київщини публікують потреби у різних місцях — сайти, Facebook, Instagram. Людині, яка хоче допомогти, складно зрозуміти, кому і чим саме.
2. **Карта (1 хв).** Заголовок одразу каже, скільки притулків потребує допомоги просто зараз. Фільтр «Харчування» → «Для малюків». Відкрити Gostomel Shelter: потреби, маршрут, донат.
3. **Бот (1,5 хв).** `/start` → «Зрозуміло!» → «Усі притулки» → SOS → «Зв'язатися». Потім «Фільтр» → «Волонтерство та авто».
4. **Головне — одна база (1 хв).** У терміналі `python scripts/demo_sync.py`. Оновити карту — нова потреба в SOS. Відкрити SOS у боті — те саме. `--undo` — зникло всюди.
5. **Дані (30 с).** 10 реальних притулків, у кожного посилання на джерело й дата перевірки (`docs/DATA_SOURCES.md`).
6. **Що далі (30 с).** Кабінет притулку для самостійного оновлення потреб, сповіщення в боті про термінові потреби, більше міст.

**Якщо щось впало:** карта працює без бота, бот показує «сервер недоступний» — пояснити, що це і є перевірка помилок з тижня 3.
